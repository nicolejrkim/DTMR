# Unitree G1 (29-dof) tracking model

Derived from the MuJoCo Menagerie `unitree_g1` description (Unitree Robotics,
BSD-3-Clause, see LICENSE), itself from Unitree's `g1_29dof_rev_1_0.xml`: torque
actuators (`g1_mjx_torque.xml`), the tracking scene (`scene_mjx_torque_tracking.xml`)
with its collision set and the `home` / `knees_bent` keyframes. The collision geometry
follows the Menagerie MJX variant (MuJoCo Playground, Zakka et al., 2025).
