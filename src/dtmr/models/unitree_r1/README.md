# Unitree R1 (24-dof) tracking model

Derived from the Unitree R1 description (`r1_mocap_29dof.xml`, Unitree Robotics, BSD-3-Clause, see LICENSE):
kinematics, inertia and joint order unchanged; the 5 mocap-only padding joints are dropped and torque actuators plus the
tracking-scene collision set are added for this tracker.
